# 使用指南

[返回首页](../README.md) · [English](USAGE.en.md) · [徽章与数据来源](DATA.md)

## 安装

Chrome 用户可从 [Chrome 应用商店](https://chromewebstore.google.com/detail/pjeccpgooejgnnbcjickjcgoamnghile) 免费安装。安装后打开 Google Scholar 页面，徽章会自动出现。

### 手动安装

适用于 Edge 或希望直接使用仓库源码的用户：

1. 点击仓库的 **Code → Download ZIP**，下载并解压；也可以使用 Git clone。
2. 打开 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/`。
3. 打开「开发者模式」。
4. 点击「加载已解压的扩展程序」（Load unpacked），选择**直接包含 `manifest.json`** 的目录。GitHub ZIP 解压后通常是 `scholar-rank-main/`。
5. 打开 Google Scholar 个人主页或搜索结果页。

请选解压后的文件夹，而不是 ZIP 文件。数据和截图库已随仓库提供，无需构建、注册、API Key 或安装依赖。
保留已加载的文件夹；手动更新文件后，在扩展管理页重新加载扩展，再刷新 Scholar 页面。

### 支持的页面

个人主页、搜索结果、引用列表、相关文章和单篇论文详情浮层都会标注；翻页或点击「显示更多」后，新条目会自动补上。
支持 `scholar.google.*` 的常见国家域名，以及 `xueshu.lanfanshu.cn`、`scholar.lanfanshu.cn`、`sc.panda985.com` 等镜像。完整范围见 [manifest.json](../manifest.json)。

## 徽章与出处匹配

鼠标悬停在徽章上，可以查看完整刊名或会议名、所属领域、期刊分区和收录信息。各类徽章的含义见 [徽章与数据来源](DATA.md)。
预印本只显示平台名，不参与分级；学位论文和专利会跳过。

扩展会归一化刊名，去掉卷期页码及常见前后缀，再结合全称、简称和人工别名匹配。无法确定的结果不显示徽章。
搜索结果中的出处过长而被截断时，可选的出处补全功能会向当前 Scholar 站点请求该条目的「引用」格式，取得完整出处后再匹配；可以在设置中关闭。

## 个人主页统计

右侧 **Paper statistics** 汇总当前已加载的论文。点击评级分类可以筛选列表，再点一次清除该分类条件。
点击 **Load all papers**，扩展会连续触发 Scholar 自己的「显示更多」，显示进度并支持随时停止。
若要查看整个主页的统计，请先加载完整列表。

### 作者角色与姓名高亮

- **First (incl. co-first)**：识别第一作者；开头连续使用 `*`、`#`、`†` 或 `‡` 标记的作者按共同第一作者处理。
- **Last**：完整作者列表中的最后一位。含 `…`、`...` 或 `et al.` 的截断列表不用于判定末作，侧栏会提示数量。
- **Highlight author name**：独立控制作者姓名高亮。符合所选角色的论文显示浅黄色底色。

单作者论文可以同时命中一作与末作，统计只计一次。默认使用主页姓名匹配，在设置中可以逐行添加其他拼写或姓名别名。

姓名匹配支持：

- 连字符姓氏，如 `Brett Beaulieu-Jones` 对应 `BK Beaulieu-Jones`。
- 主页省略中间名时的作者缩写，如 `Brett` 对应 `BK`。
- 主页姓名括号内的中英文别名。
- 括号旧姓，如 `Madeleine Torcasso (Durkee)` 自动组合出 `Madeleine Durkee`，用于一作、末作和姓名高亮。

### 组合筛选

选择发表年份范围、评级分类和作者角色；勾选 **Show only highlighted papers** 可隐藏其余论文。
作者角色之间取并集，角色、年份和分类之间取交集。限制年份时，不包含年份缺失的条目；**Reset** 清除年份范围。
角色、年份和显示选项按主页保留在当前标签页中，刷新后仍保留。

### 引用指标

侧栏对比高亮论文与已加载论文的篇数、引用数、h-index 和 i10-index。
年份条件针对论文发表年份，引用数使用这些论文当前的累计引用，并非仅在所选年份中获得的引用。
指标只覆盖已加载条目，Scholar 已划线的重复引用不重复计入。

## 截图复制与下载

点击 **Copy screenshot** 生成 PNG 并复制到剪贴板，或点击 **Download screenshot** 保存图片。截图包含当前筛选后的论文列表和右侧统计，在本机生成。
如果浏览器不允许复制，请使用下载；列表很长时，可先缩小年份范围或仅显示高亮论文。

复制截图使用扩展的 `clipboardWrite` 权限，扩展不会读取剪贴板。更多权限与数据处理说明见 [隐私政策](PRIVACY.md)。

## 设置与问题排查

点击工具栏扩展图标，可快速开关扩展、切换外观；点击「打开设置」进入完整设置页。
可以逐个开关徽章、调整字号和字重、添加作者别名，以及查看打包的数据版本。

六种徽章风格为：柔和填充、描边、实心、极简文字、方角标签和低调灰阶。

遇到漏标或误标时，把 Scholar 上的出处原文粘贴到设置页的「匹配自测」框中，可以查看命中记录和匹配路径。
如果仍有问题，欢迎 [提 issue](https://github.com/Day333/scholar-rank/issues)，附上页面链接、出处或作者原文、预期与实际结果；有截图也欢迎补充。

评级数据、统计和截图库随扩展提供，不向开发者发送页面数据。浏览器提供商可能同步设置和手动填写的作者别名；出处补全和加载更多论文会请求当前 Scholar 站点，截图可能加载页面已引用的图片。详见 [隐私政策](PRIVACY.md)。
