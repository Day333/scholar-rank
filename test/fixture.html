离线预览：Google Scholar 个人主页结构

这个页面复刻了 Scholar 个人主页的 DOM 结构，并用一套假的 chrome.* API 直接跑真实的 content script， 用来在不打开 Scholar 的情况下检查徽章渲染效果。需通过 node tools/serve.mjs 起的本地服务打开。

下面都是真实论文，被引次数取自 Semantic Scholar（2026-07-28 查询）。Google Scholar 自己的计数通常更高， 这里只是为了让示意图里的数字不是编的。
